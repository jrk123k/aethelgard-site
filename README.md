# Aethelgard

Public stub site for **Aethelgard** — Gloria Tonante, Orchestra Sinfonica Luminar, and Apex Veloce — and the inaugural short engagement at **Teatro Luminar, Milano**.

This is the official project page Jim can cite for *Aethelgard: Live at Teatro Luminar*. It is a static, one-page house record: no paid hosting, no comments in this version.

## Public URL

After GitHub Pages is enabled:

**https://jrk123k.github.io/aethelgard-site/**

## Enable GitHub Pages

Pages is not always switched on automatically. In the GitHub UI:

1. Open the repository: https://github.com/jrk123k/aethelgard-site
2. Go to **Settings → Pages**
3. Under **Build and deployment**:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
4. Click **Save**
5. Wait a minute, then visit https://jrk123k.github.io/aethelgard-site/

The site is plain HTML and CSS at the repository root (`index.html`, `styles.css`). A `.nojekyll` file is included so GitHub does not process the tree with Jekyll.

## Local preview

Serve the root directory with any static file server, for example:

```bash
python3 -m http.server 8080
```

Then open http://127.0.0.1:8080/
